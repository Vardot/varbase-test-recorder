# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-23

### Added

- Electron desktop recorder for Drupal and Varbase browser workflows
- React-based workspace with step editing, scenario management, assertions, replay, export, and configuration tabs
- Structured action recording for navigation, click, type, select, check, upload, submit, wait, assertions, CKEditor, dialog, dropbutton, media, and tabledrag interactions
- Drupal-aware URL pattern detection and CRUD-related variable capture
- Playwright `.spec.js` generation with helper functions and optional CRUD templates
- Replay engine with step status tracking, speed control, step mode, login option, and failure handling
- Save and load session support
- Project integration wizard and Playwright scaffold templates
- Iframe-aware element picking, replay targeting, and frameLocator generation
- Initial publication docs, contribution guide, community templates, and GPL licensing
